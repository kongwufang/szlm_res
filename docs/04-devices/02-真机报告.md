## 5.3 反调试机制**完整暴露**（核心收获之一）

```
[探测] fopen("/proc/self/maps")   bt=libnesec.so+0xa7f48 <- libc.so+0x23318
[探测] fopen("/proc/self/status") bt=libnesec.so+0x7b4c4 <- libc.so+0x23318
[退出] kill(...)   bt=libdu.so+0xc2638 <- 0xc2e2c <- 0x91b5c <- 0x12ed20 <- 0x125ed0 <- libc
[退出] pthread_exit bt=libc.so+0x830a4
```

- `libnesec.so`（易盾加固）= **探测器**：扫 `/proc/self/maps` 找 frida-agent、扫 `/proc/self/status` 读 `TracerPid`
- `libdu.so+0xc2638` = **执行器**：调 `kill()` 自杀
- **规避手法**：不直接崩，而是让 Activity 退到后台 → 手表激进内存策略负责回收，**伪装成"内存不足/回桌面"**

**关键判据实验**：
- 无 frida：酷安稳定前台（12/13 采样）
- 空脚本 attach（零 hook）：attach 瞬间退后台 + 进程消失
- => 与 hook 无关，纯 attach 即触发

## 5.4 解法：frida 隐身（100% 有效）

拦截 `fopen`/`open`/`openat`，把 `/proc/self/maps`、`/proc/self/status`
**重定向到过滤副本**（剔除含 frida / gum- / gmain / gdbus / linjector / 27042 / xposed / substrate / magisk 的行）：

```js
const CM = '/data/data/com.coolapk.market/files/.cm';   // app 私有目录才可写
const CS = '/data/data/com.coolapk.market/files/.cs';
['fopen','open','openat'].forEach(function(fn, idx){
  Interceptor.attach(Module.findExportByName(null, fn), { onEnter(args){
    const p = (idx===2?args[1]:args[0]).readCString();
    if (p.startsWith('/proc/self/maps'))   (idx===2?args[1]:args[0]).writePointer(Memory.allocUtf8String(CM));
    if (p.startsWith('/proc/self/status')) (idx===2?args[1]:args[0]).writePointer(Memory.allocUtf8String(CS));
  }});
});
```

**效果**：进程寿命 **6 秒 → 130+ 秒**（pid 全程不变）；一次采集可稳定运行到采集窗结束。
