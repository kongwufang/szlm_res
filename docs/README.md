## ⚠️ 必读

### [99-已推翻的结论.md](99-已推翻的结论.md)

**本项目最重要的文档之一。**

逆向过程中产生过若干**中间结论**，它们被写进了当时的文档，后来被实验推翻。
如果只读到中间文档，很容易被误导。

这份文档逐条列出 12 个被推翻的结论：

```
当时怎么想的 → 为什么错 → 怎么被推翻的 → 正确结论是什么
```

其中最有误导性的是第 1 条：

> **"`mIS` 是唯一钥匙"** —— 这个结论曾写进多份文档，
> 并在此基础上做了大量后续推断（"需要解出 36 字符混淆串"……）。
> 实际上把 `mIS` 随机化后重新扫描，会发现它与设备识别**完全无关**。

**建议：读任何归档文档前，先扫一眼这份清单。**
