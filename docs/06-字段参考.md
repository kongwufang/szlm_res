## 角色速查

```
★ 锚点 / 必需（6 个）   DUv 3mS 75c 2cO sfOo foO
☆ 与识别无关（1 个）    mIS
· 其余 72 个字段        全部不参与设备识别
```

**最小可用 body 只需 8 个字段：**

```
DUv + 3mS + 75c + 2cO + sfOo + foO + AAA + BBB
```

---

## 六个必需字段

| 字段 | 示例值 | 格式要求 | 性质 |
|---|---|---|---|
| `DUv` | `com.coolapk.market` | **精确匹配**，大小写敏感 | 应用身份 |
| `3mS` | `v9.0.1` | 小写 `v` + 版本 ≥ 9.x | SDK 版本 |
| `75c` | `11e7b222…15eb` | apiKey；可省略，给了就必须精确 | 常量 |
| `2cO` | `1791105420.764024281` | `秒.纳秒`，纳秒非零，±24h 窗 | ★ 锚点 |
| `sfOo` | `801C14F` | 7 位大写十六进制 | ★ 锚点 |
| `foO` | `RP|Q|zQKOJ~I~}Q` | 15 字符混淆串 | ★ 锚点 |

## 完整字段表（79 个）

### 应用 / 系统信息

|---|---|---|---|

### 网络

| 键 | 类型 | 示例 | 语义推断 |
|---|---|---|---|
| `zpA` | str | `WIFI` | 网络类型 |

### 时间戳

| 键 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `Qg1` / `LMi` | int | 1790980402778 | 毫秒时间戳（两次注册相同） |
| `2cO` | str | `1791105420.764024281` | ★ 锚点 |
| `za7` | str | `1_1791105420_` | 格式化 `1_<秒>_` |

### 哈希类

| 键 | 长度 | 跨注册 | 跨设备 | 判定 |
|---|---|---|---|---|
| `K5f` | 32 | 变化 | — | MD5 |
| `ne8` | 32 | 恒定 | **相同** | **常量，非指纹** |
| `w91` | 32 | 恒定 | 不同 | ★ 设备指纹 |
| `gEd` | 32 | 恒定 | 不同 | ★ 设备指纹 |
| `6yY` | 64 | 恒定 | 不同 | ★ 设备指纹（SHA256） |
| `75c` | 42 | 恒定 | 相同 | ★ apiKey 常量 |

> ⚠️ **注意**：`w91` / `gEd` / `6yY` 虽然是设备指纹，但**不参与设备识别**
> —— 整类随机化后服务器照样返回真 DUID。

### ★ 锚点三元组

| 键 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `sfOo` | str | `801C14F` | 7 位 hex，每次注册都变 |
| `foO` | str | `RP|Q|zQKOJ~I~}Q` | 15 字符，每次注册都变 |
| `2cO` | str | `1791105420.764024281` | 时钟读数 |
