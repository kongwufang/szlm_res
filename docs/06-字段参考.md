## 角色速查

```
★ 锚点 / 必需（6 个）   DUv 3mS 75c 2cO sfOo foO
☆ 与识别无关（1 个）    mIS
· 其余 72 个字段        全部不参与设备识别
```

**最小可用 body 只需 8 个字段：**

```
DUv + 3mS + 75c + 2cO + sfOo + foO + AAA + BBB
```

---

## 六个必需字段

| 字段 | 示例值 | 格式要求 | 性质 |
|---|---|---|---|
| `DUv` | `com.coolapk.market` | **精确匹配**，大小写敏感 | 应用身份 |
| `3mS` | `v9.0.1` | 小写 `v` + 版本 ≥ 9.x | SDK 版本 |
| `75c` | `11e7b222…15eb` | apiKey；可省略，给了就必须精确 | 常量 |
| `2cO` | `1791105420.764024281` | `秒.纳秒`，纳秒非零，±24h 窗 | ★ 锚点 |
| `sfOo` | `801C14F` | 7 位大写十六进制 | ★ 锚点 |
| `foO` | `RP|Q|zQKOJ~I~}Q` | 15 字符混淆串 | ★ 锚点 |

## 完整字段表（79 个）

### 应用 / 系统信息

| 键 | 类型 | 示例 | 语义推断 |
|---|---|---|---|
| `DUv` | str | `com.coolapk.market` | ★ 包名 |
| `Zrs` | int | 2609151 | versionCode |
| `EV2` | str | `16.6.2` | versionName |
| `h6Z` | str | `酷安` | 应用名 |
| `GVp` | str | `coolapk` | 渠道 |
| `SAN` | int | 27 | Android API level |
| `R41` | str | `8.1` | Android 版本 |
| `R37` | str | `TK Watch` | 厂商 / brand |
| `R3d` | str | `TK Watch` | 机型 / model |
| `R63` | str | `running` | 进程状态 |
| `D32` | int | 4 | CPU 核数 |
| `Ra` | str | `ABSENT` | 未知（可能指某权限缺失） |

### 网络

| 键 | 类型 | 示例 | 语义推断 |
|---|---|---|---|
| `zpA` | str | `WIFI` | 网络类型 |
| `wSK` | str | `10.0.0.37` | 内网 IP |
| `AYk` / `P1J` | str | `13A365:CCAF40:AD4AA9` | MAC 三元组 |
| `YWu` | str | `127.0.0.1+localhost;::1+ip6-localhost;` | /etc/hosts 内容 |
| `fPV` | str | `CN,zh` | 国家,语言 |
| `G8U` | dict | `{"MYA":…,"H4S":…}` | 网络详情（嵌套） |
| `Q23` | str | `user:e4e40166.0+CN=…CA证书;…` | 证书列表 |

### 时间戳

| 键 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `Qg1` / `LMi` | int | 1790980402778 | 毫秒时间戳（两次注册相同） |
| `2cO` | str | `1791105420.764024281` | ★ 锚点 |
| `za7` | str | `1_1791105420_` | 格式化 `1_<秒>_` |

### 哈希类

| 键 | 长度 | 跨注册 | 跨设备 | **输入是什么** |
|---|---|---|---|---|
| `K5f` | 32 | 变化 | — | `MD5(上报时间串 + pid + rand() + tid)` |
| `ne8` | 32 | 恒定 | **相同** | **`libdu.so` 自身的 MD5** —— 用来检测 SDK 是否被替换 |
| `w91` | 32 | 恒定 | 不同 | **`/system/fonts` 文件名列表的 MD5** |
| `gEd` | 32 | 恒定 | 不同 | **`libreference-ril.so` 或 `libc.so`（32 位）的 MD5** |
| `6yY` | 64 | 恒定 | 不同 | **Widevine `deviceUniqueId`（hex 原样）** |
| `75c` | 42 | 恒定 | 相同 | **apiKey 常量**，可省略 |

> ⚠️ **注意**：`w91` / `gEd` / `6yY` 虽然是设备指纹，但**不参与设备识别**
> —— 整类随机化后服务器照样返回真 DUID。
>
> **⇒ 这解释了我原来做的 73080 次组合穷举为什么零命中：**
> 输入不是报文里的字段，而是**文件系统里的内容**。

### ★ 锚点三元组

| 键 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `sfOo` | str | `801C14F` | 7 位 hex，每次注册都变 |
| `foO` | str | `RP|Q|zQKOJ~I~}Q` | 15 字符，每次注册都变 |
| `2cO` | str | `1791105420.764024281` | 时钟读数 |

### 混淆串 / 编码字段（16 个）

**这些不是"随机混淆"，是可解的编码。** 解法见 [⑧ 破解字段编码](08-破解字段编码.md)。

解码后（`K=12`，D1H 那份）：

| 字段 | 上报值（示例） | **解码后** | 含义 |
|---|---|---|---|
| `foO` | `DEo?qBmCp=DoDq>` | `288daec8ec17639` (+校验位) | ANDROID_ID 前 15 位 |
| `sfOo` | `FD2C5E4` | — | 上面那 16 位的校验值 |
| `dLH` | `nmDnD>E@A9@A?D<…` | `c009c04e-f985-42ba-b41a-f49d0345988b` | boot_uuid |
| `dJs` | `IMPIIJPK}KJQKIJ…` | `150100525831424d420751004057c400` | eMMC CID |
| `p1m` | `PIIJ2NMINI` | `0x51004057` | eMMC 序列号 |
| `zvW` | `\|\|RJI}JKQKQR{}…` | `06fb5d9bd9d8921842811d8021d95c6c` | Canvas 指纹 MD5 |
| `5Tv` | `\|\|I}z LRO~\|…` | `72f3b7de3fac3ef63923efbaadd02cdc` | libcutils.so MD5 |
| `52J` | `RLOJREKKKESEKMP…` | `7754:1,11548:20,11938:20,…` | 10 个路径的 inode:dev |
| `Bos` | `PQRRJQJRNPERRRIG…` | `1735690118.109999897,…` | 目录访问/修改时间 |
| `IJK` / `ura` | `PRMILMMIJPERRRO…` | `1735789212.169999993,…` | 同上 |
| `IAI` | `JPMIMILNNPERRRLG…` | `1735690119.539999896,…` | 同上 |
| `aFw` | `NRMIRJMIJPERRRKG…` | `1735789209.729999994,…` | 同上 |
| `KyU` | `JRMIPNLIJPRJIRGR…` | `1791108007.60040123` | 宿主 shared_prefs 目录时间 |
| `ibF` | `IIIFFI` | `00-0-0` | 根分区 fsid-blocks-inodes |
| `UOv` | `NQQLRLRQJPKQRJGK…` | 开机时刻 | CLOCK_REALTIME − CLOCK_BOOTTIME |
| `mIS` | `5f58fb85c.12b5:ee…` | boot_id UUID | `/proc/sys/kernel/random/boot_id` |

**★ 关键观察**：同一设备两次注册，`dJs` / `p1m` / `zvW` / `5Tv` / `52J` / `Bos`
**逐字节相同**（硬件与旧目录），只有 `dLH` 和带当前时间的字段变化。

**⇒ 这反证了解码正确**：K 若选错，不可能 6 个字段同时对齐。
