## 三、★ 关系验证结果

### 3.1 `sfOo = 4A213D3` 不是任何 hex 字段的前缀

```
K5f  前 7 = B2F1481  ≠ 4A213D3
ne8  前 7 = 97313E2  ≠
w91  前 7 = 922BD64  ≠
gEd  前 7 = 7BEE651  ≠
6yY  前 7 = C48ED04  ≠
75c  前 7 = 11E7B22  ≠
⇒ 与它们都无关
```

**★ `0x4A213D3` = 十进制 77725651 —— 也可能只是个数字。**

### 3.2 `foO` 与 `mIS` 无直接派生关系

```
foO 长度 15,  mIS 长度 36
foO ⊄ mIS（不是子串、不是前缀）
foO 字符集 = (*TWXYZ]        （8 种）
mIS 字符集 = &'()*+QTWXZ\    （12 种）
⇒ foO 字符集 ⊂ mIS 字符集
foO XOR mIS[:15] = 0002 7d02 0172 7c72 0d73 7670 7201 00
                  ↑ 首字节为 0，说明【首字符相同（都是 W）】
```

**⇒ 二者同源（同一套混淆表），但不是简单截断。**

### 3.3 混淆串的共同特征

```
15+ 个字段（mIS / foO / yzW / zvW / 5Tv / 52J / Bos / IJK / ibF / IAI / aFw / KyU / UOv / dLH / 90P / LAh）
· 字符全部落在 0x21~0x7E 的一个受限子集
· 互相之间字符集高度重叠
· 长度各异（15~96）
⇒ 强烈提示：【同一套字符串混淆机制】的产物
   （文档已确认 libdu 用的是【标准 base64 表】做索引 —— 那这些应该是
     base64 输出再经某个变换）
```
